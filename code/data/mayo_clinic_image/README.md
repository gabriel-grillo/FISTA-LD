# Instructions for data

For the experiments we used the data from the *AAPM Low Dose CT Grand Challenge Dataset* [[1]](#1)[[2]](#2).

In this subdirectory, you must unzip "full_3mm.zip", which can be downloaded at https://aapm.app.box.com/s/eaw4jddb53keg1bptavvvd1sf4x3pe9h/file/856956352254.
