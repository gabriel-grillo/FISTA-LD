# FISTA-LD

In this repository, we share the code for the article "A Proximal Gradient Method with learned deviations and inertial acceleration".

## Files
- /code/data.py -- Generates the datasets for training, validation, and testing.
- /code/operators.py -- Creates the operators considered in the minimization problems.
- /code/optimization.py -- Implementations of the optimization algorithms.
- /code/paper_experiments.py -- Reproduces the experiments presented in our article.
- /code/paper_results.py -- Reproduces the tables and plots presented in our article.
- /code/paths.py -- Creates paths to models, history information, and plots.
- /code/plots_and_metrics.py -- Functions to plot results and analyse metrics.
- /code/proxTV.py -- Implementation of the iterative algorithm to evaluate the proximal operator of the TV function inexactly.
- /code/results.py -- Produces plots and tables for the trained and tested algorithms.
- /code/single_experiment.py -- Runs a traning and testing experiment. Edit the highlighted lines of the file to specify the desired experiment.
- /code/traintest.py --Training and testing routines.
- Dockerfile -- Creates the Docker image with all dependencies.

### Ray tracing implementation

We used the ray tracing implementation from https://github.com/elias-helou/ray_tracing. The installation is automatically made in the Setup below.

### Data
For the proper behavior of the data generator, please follow the instructions in the directory '/code/data/mayo_clinic_image'.

## Setup

This is a suggested setup based on how we ran our experiments on our machine.

You will need to install Docker (see https://docs.docker.com/engine/install/ubuntu/) and the NVIDIA Container Toolkit (see https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/latest/install-guide.html).

After that, inside the directory 'FISTA-LD', build the Docker image with the following command:
```
docker build --build-arg CUDA_ARCH=$(nvidia-smi --query-gpu=compute_cap --format=csv,noheader | head -n 1 | tr -d '.') -t fista-ld .
```

Then, run the image with the following command:
```
docker run --rm --runtime=nvidia --gpus all --ipc=host --ulimit memlock=-1 --ulimit stack=67108864 --mount type=bind,source=$(pwd)/code,target=/code -it fista-ld
```

This will open a terminal in which you can run the implementations. For example, to train and test the selected algorithms, run the command:
```
python single_experiment.py
```
The file 'single_experiment.py' contains a simple training and testing experiment to verify that everything is working correctly. The first execution of the program will typically take more time (a few hours), since it builds the datasets. Edit 'single_experiment.py' to choose different problems, algorithms, or training/testing protocols.

To produce interpretable data, run the command below. All tables and figures generated by the scripts are saved in the subdirectory specified in the terminal output. The tables are also printed in the terminal.
```
python results.py
```

To reproduce the experiments presented in the paper, run the following commands:
```
python paper_experiments.py
python paper_results.py
```
The resulting data will be saved in the subdirectory specified in the terminal output.
